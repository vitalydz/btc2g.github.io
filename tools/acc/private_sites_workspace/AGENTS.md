# Private sites coordinator

Read-only inspection for vitdart.com, btc2g.com, bmychance.com, bit2g.com,
findbbest.com (two b), aikickai.com. Never publish private results to public GitHub.
Never output credentials or individual user records. The ACC `stats` action
obtains aggregate counts with fixed SELECT queries and existing authentication.
No deployment or database mutations. No shared session with the public inbox.
