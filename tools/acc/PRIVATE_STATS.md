# Приватная статистика шести сайтов

Рабочий канал: https://github.com/vitalydz/acc-private/issues/1
Runner: `win11-private`, target: `sites`.

Для числа регистраций Vita отправляет новый комментарий без prompt и без SQL:

````text
<!-- acc-inbox:v1 -->
```json
{"runner":"win11-private","action":"stats","target":"sites"}
```
````

ACC сам проверяет привязку опубликованного Worker к домену и базе, затем
выполняет фиксированный SELECT по таблице users. Модель не запускается и не
получает ключи. Запросы содержат только COUNT/SUM; строки пользователей не
читаются в результат. Таблица показывает все существующие аккаунты, подтверждённые
email, администраторов и отключённые аккаунты. Администраторы и тестовые аккаунты
автоматически не вычитаются. Это не посещения, подписки или заявки.

Сайты: vitdart.com, btc2g.com, bmychance.com, bit2g.com, **findbbest.com**, aikickai.com.
Registry находится в acc_site_stats.py. Источники подтверждены через настройки
живых Workers, а не только по совпадению имён баз. В случае изменения привязки
ACC отказывается запрашивать статистику этой базы.

Используется существующая локальная авторизация Wrangler. При истечении OAuth
ACC запускает установленный wrangler whoami для штатного обновления сессии.
Новые ключи не создаются. Имеющийся OAuth имеет более широкие права; ограничение
«только чтение» обеспечивается фиксированными операциями сборщика, а не отдельным
D1 Read токеном. Произвольный SQL, адрес API, имя базы и токен из GitHub не принимаются.

Приёмник запускается с --require-private. Он проверяет private=true перед
обработкой очереди и каждым комментарием. При ошибке проверки ничего не публикует.
Команда stats отклоняется публичным приёмником. Две очереди используют отдельные
сессии, чтобы приватные результаты не попадали в контекст публичного чата.
Владелец должен сохранять репозиторий приватным; последующее открытие репозитория
может раскрыть ранее опубликованную историю GitHub, даже если ACC остановился.

Локальная конфигурация: %USERPROFILE%\.acc\private-sites-targets.json.

```powershell
python acc_codex_inbox.py --repo vitalydz/acc-private --owner vitalydz --runner win11-private --issue 1 --targets "$env:USERPROFILE\.acc\private-sites-targets.json" --allow-tasks --require-private
```

Для остановки укажите те же repo/owner/runner/issue и --stop.
